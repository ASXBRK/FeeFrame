# FeeFrame
Advice fee builder for Australian financial advisers and paraplanners.

Scope, calculate, and justify fees for initial SOA and ongoing service — with a client-facing paragraph ready to paste into an email or SOA.

## Why

Xplan and Wealthsolver solve product fees, not advice fees. No tool handles the advice fee side well, and no tool supports all fee models in one place. FeeFrame fills that gap.

## What it does

- Supports flat fee, percentage, tiered, and subscription models
- Calculates cost-recovery baseline from actual time and costs
- Shows implied hourly rate as a business health check
- Generates a plain English client-facing fee justification
- PDF export for file notes and client meetings
- Pure client-side — no backend, no data leaves your browser

## Built with

React, Vite, Tailwind CSS
